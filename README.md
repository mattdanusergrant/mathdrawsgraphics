An interactive, single-file **math playground**: a gallery of animated math examples — each with a plain-language explanation of the maths *and* the live code that draws it. 22 examples across geometry, fractals, chaos, number theory and signals, each with a "How it works" explainer, editable live source, and PNG/SVG export.
